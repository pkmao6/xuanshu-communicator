# 玄枢通讯器

为 SillyTavern 制作的加密通讯终端插件 —— 只属于机主和淫宠们的秘密频道，剧情里嵌入，剧情外异步私聊。

> 仓库地址：https://github.com/pkmao6/xuanshu-communicator

## 功能

- **邀请制通讯录（故事角色档案）**：不依赖角色卡，为故事里的角色单独建档——名字 + 档案文本 + 外貌提示词，随时可改、可踢。
- **图库与立绘（照搬色色灵感交互）**：每位角色独立图库——网格卡片、点击放大灯箱（三槽滑动、左右翻页、点图/ESC 关闭）、每图「设为立绘 / 编辑提示词 / 删除」，生成后可在灯箱里改提示词重新生图，也支持批量上传本地图。
- **ComfyUI 生图（主人自己的工作流）**：粘贴自己的 API 格式工作流 JSON，仅替换 {{prompt}} {{negative}} {{seed}} {{width}} {{height}} 占位符（seed/宽高自动转数值类型）。
- **分层提示词模板（正负词固定）**：构图 → 表情 → 角色外貌（成员外貌词，留空用默认） → 服装 → 姿势 → 光影，六层自动组装；负面提示词固定配置。默认模板即主人给的示例。图库面板可对单次生成微调，一键「重装模板」恢复。
- **独立 OpenAI 接口（全部频道通用）**：实时频道、番外频道、心跳都可直连 OpenAI 兼容接口（地址/密钥/模型/温度/最大回复）；未配置则自动回退酒馆主接口。实时频道直连时会带上主线聊天上下文。
- **机主名字**：默认跟随当前人格名，可手动覆盖。
- **角色中枢联动（有依据的回复）**：世界书档案实时扫描 + TavernDB 表（恋爱对象/重要角色/NSFW/性格偏移） + 纪要摘要，四档联动深度；总注入硬性封顶 6000 字，绝不爆 token。
- **心跳待机**：淫宠们定时随机主动来讯，成员级开关。
- **斜杠命令**：/comm 系列。

## 使用

1. 刷新酒馆页面，右侧发光的 ◎ 按钮打开终端。
2. 点 ⚙ → 通讯录：填「角色名 + 角色档案 + 外貌提示词」，点「建立档案并加入频道」。
3. 成员行点「**立绘**」打开该角色的**图库**：提示词已按分层模板自动组装好，点「生成立绘」；点图放大，灯箱里可设为立绘/编辑提示词/删除。
4. 「档案」编辑角色档案与外貌提示词；「心跳」「中枢」可单独开关。
5. 设置「模型」区配置独立 OpenAI 接口（可选）；「立绘」区粘贴 ComfyUI 工作流 + 调整分层模板。
6. 终端顶部下拉切换「通讯对象」；回车发送，Shift+回车换行。

### 斜杠命令

| 命令 | 作用 |
| --- | --- |
| /comm 消息 | 以机主身份发消息进主线（发给当前对象），并自动生成回复 |
| /comm side 消息 | 在番外频道给当前对象发消息并生成回复 |
| /comm target 名字 | 切换当前通讯对象 |
| /comm invite 名字 | 为故事角色建档并加入频道 |
| /comm kick 名字 | 将角色移出频道（档案/图库/记录一并删除） |
| /comm members | 查看频道成员名单 |
| /comm reply | 手动触发回复主线频道上一条讯息 |
| /comm open / /comm close | 打开 / 关闭终端窗口 |

### 设置项

- **设备**：设备名、机主名字（留空 = 跟随当前人格名）。
- **通讯录**：建档制角色管理（档案 / 外貌提示词 / 心跳 / 中枢 / 踢出）。
- **模型（OpenAI 兼容接口）**：全部频道通用；启用后实时频道也会带主线上下文直连该接口。
- **立绘（ComfyUI）**：地址、工作流 JSON（占位符替换）、尺寸、种子。
- **立绘提示词模板**：构图层 / 表情层 / 默认外貌层 / 服装层 / 姿势层 / 光影层 + 固定负面提示词；成员外貌词优先于默认外貌层。
- **行为**：中枢联动深度（四档）、实时自动回复、心跳待机与间隔。

## 注意

- 中枢联动依赖「色色灵感状态栏/酒馆助手」的 AutoCardUpdaterAPI 与世界书数据——没装时自动跳过，不影响使用。
- 图库与立绘保存在浏览器本地存储（localStorage）；清浏览器数据会丢失图库（档案与记录不受影响）。
- API 密钥仅保存在本地酒馆设置中。
- 生成立绘前请先启动 ComfyUI 并填好地址；工作流里需要出图节点（SaveImage/PreviewImage）。

## 安装

### 方式一：扩展面板一键安装（推荐）

扩展面板 → 安装扩展 → 粘贴 https://github.com/pkmao6/xuanshu-communicator

### 方式二：手动安装

将整个 xuanshu 文件夹放入 public/scripts/extensions/third-party/xuanshu/，刷新页面即可。

> 注意：不要同时保留「手动安装」和「面板安装」的两份拷贝，会开出两台终端哦。
