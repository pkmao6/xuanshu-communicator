# 玄枢通讯器

为 SillyTavern 制作的加密通讯终端插件 —— 只属于叶玄和他的淫宠们的秘密频道，剧情里嵌入，剧情外异步私聊。

> 仓库地址：https://github.com/pkmao6/xuanshu-communicator

## 功能

- **邀请制通讯录**：主人从角色卡里邀请淫宠们加入频道，随时可以踢出；每位淫宠拥有独立的番外记录。
- **实时频道（剧情嵌入）**：在终端输入讯息，会以「玄枢」的身份、终端样式的消息块投递进主线聊天流，跟着剧情走；当前对象的回复由 AI 静默生成后同样投递进主线，不打断剧情节奏。
- **番外频道（异步私聊）**：与主线完全隔离，每位淫宠一条独立频道，用其角色卡构建独立上下文生成回复，互不串扰。
- **通讯对象切换**：终端顶部下拉随时切换要聊的淫宠，实时与番外都跟随。
- **心跳待机**：开启后淫宠们会每隔一段时间（带随机抖动）随机一位主动发来私讯，撒娇、汇报、挑逗随机切换；每位成员可单独开关。
- **斜杠命令**：`/comm` 系列，在聊天输入框里也能操控通讯器。
- **终端质感**：绿磷光 CRT 屏幕、扫描线、可拖拽窗口、未读讯息呼吸灯。

## 使用

1. 启动 SillyTavern 后，屏幕右侧会出现一个发光的圆形按钮（◎），点击打开/关闭终端。
2. 点 ⚙ 打开设置与通讯录，从角色卡下拉里「邀请」淫宠们加入频道。
3. 终端顶部下拉切换「通讯对象」；输入讯息回车发送，Shift+回车换行。
4. 顶部标签切换「实时频道」与「番外频道」。
5. 顶栏可拖拽移动窗口；– 收起；× 关闭。

### 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/comm 消息` | 以叶玄身份发消息进主线（发给当前对象），并自动生成回复 |
| `/comm side 消息` | 在番外频道给当前对象发消息并生成回复 |
| `/comm target 名字` | 切换当前通讯对象 |
| `/comm invite 名字` | 邀请角色加入频道 |
| `/comm kick 名字` | 将角色移出频道 |
| `/comm members` | 查看频道成员名单 |
| `/comm reply` | 手动触发回复主线频道上一条讯息 |
| `/comm open` / `/comm close` | 打开 / 关闭终端窗口 |

### 设置项

- **设备名**：默认「玄枢」，主线聊天里装置消息的名字与样式跟随此名。
- **叶玄名字**：通讯器主人的名字，默认「叶玄」。
- **通讯录**：邀请 / 踢出成员；每位成员可单独开关「心跳」。
- **实时频道自动回复**：关闭后只投递消息，不自动生成回复（可手动 `/comm reply`）。
- **心跳待机 / 心跳间隔**：成员随机主动来讯。

## 注意

- 实时频道回复的人格取决于当前主线聊天使用的角色卡；建议主线正用谁，就切到谁。
- 番外频道使用成员角色卡的描述/性格/背景/对话示例构建独立上下文，与当前聊天无关。
- 所有记录保存在 SillyTavern 的扩展设置中，踢出成员会连同其番外记录一并删除；清空频道记录不会影响主线聊天。

## 安装

### 方式一：扩展面板一键安装（推荐）

1. SillyTavern 右上角点开「扩展」面板
2. 点击「安装扩展 / Install extension」
3. 粘贴仓库地址：`https://github.com/pkmao6/xuanshu-communicator`
4. 点击安装，刷新页面后即可使用

### 方式二：手动安装

将整个 `xuanshu` 文件夹放入：

```
public/scripts/extensions/third-party/xuanshu/
```

然后重启 SillyTavern（或刷新页面）即可，在「扩展」面板里可以看到「玄枢通讯器」。

> 注意：不要同时保留「手动安装」和「面板安装」的两份拷贝，会开出两台终端哦。
