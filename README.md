# 玄枢通讯器

为 SillyTavern 制作的加密通讯终端插件 —— 只属于机主和淫宠们的秘密频道，剧情里嵌入，剧情外异步私聊。

> 仓库地址：https://github.com/pkmao6/xuanshu-communicator

## 功能

- **邀请制通讯录（故事角色档案）**：不依赖角色卡，为故事里的角色单独建档——名字 + 档案文本（外观、性格、关系、背景），随时可改、可踢。
- **角色立绘**：每位角色可生成/上传立绘——生成走 **ComfyUI API**（内置默认工作流，地址/模型/尺寸/步数/风格词可配），也支持直接上传本地图片；立绘显示在通讯录与终端头部。
- **实时频道（剧情嵌入）**：以「玄枢」身份、终端样式消息块投递进主线聊天流，跟剧情走；回复由酒馆主接口静默生成后注入。
- **番外频道（异步私聊）**：与主线完全隔离，每位淫宠一条独立频道；回复可走**独立 OpenAI 兼容接口**（地址/密钥/模型/温度自配），没配则自动回退酒馆主接口。
- **机主名字**：不再写死「叶玄」，默认跟随当前人格名，也可手动指定。
- **角色中枢联动（有依据的回复）**：每次生成前实时读取——
  - 世界书：扫描当前角色卡世界书里属于该角色的档案条目；
  - **TavernDB 表**：经酒馆助手 AutoCardUpdaterAPI 读取恋爱对象表/重要角色表/NSFW信息表/人物性格偏移表 + 纪要表；
  - **严格限流**：世界书≤4000 字、角色表≤2000 字、纪要只取该角色最近 5 条摘要≤800 字，总注入≤6000 字，绝不爆 token。联动深度可四档调节（关闭/仅世界书/加角色表/全部）。
- **心跳待机**：淫宠们定时随机主动来讯，成员级开关。
- **斜杠命令**：/comm 系列。

## 使用

1. 刷新酒馆页面，右侧发光的 ◎ 按钮打开终端。
2. 点 ⚙ → 通讯录：填「角色名 + 角色档案」，点「建立档案并加入频道」。
3. 成员行点「档案」编辑档案、**生成立绘**（ComfyUI）或上传本地图；「心跳」「中枢」可单独开关。
4. 终端顶部下拉切换「通讯对象」；回车发送，Shift+回车换行。
5. 「模型」区配置独立 OpenAI 接口（可选，不配则用酒馆主接口）；「立绘」区配置 ComfyUI。
6. 「中枢联动」默认「全部」，担心 token 可调低档位。

### 斜杠命令

| 命令 | 作用 |
| --- | --- |
| /comm 消息 | 以机主身份发消息进主线（发给当前对象），并自动生成回复 |
| /comm side 消息 | 在番外频道给当前对象发消息并生成回复 |
| /comm target 名字 | 切换当前通讯对象 |
| /comm invite 名字 | 为故事角色建档并加入频道 |
| /comm kick 名字 | 将角色移出频道（档案/立绘/记录一并删除） |
| /comm members | 查看频道成员名单 |
| /comm reply | 手动触发回复主线频道上一条讯息 |
| /comm open / /comm close | 打开 / 关闭终端窗口 |

### 设置项

- **设备**：设备名、机主名字（留空 = 跟随当前人格名）。
- **通讯录**：建档制角色管理，成员级「心跳」「中枢」开关。
- **模型（OpenAI 兼容接口）**：启用独立接口后，番外/心跳直连该接口（地址、密钥、模型、温度、最大回复）。
- **立绘（ComfyUI）**：地址、模型文件、正负向提示词、尺寸、步数/CFG；生成立绘时正提示词 = 角色档案摘要 + 风格词。
- **行为**：中枢联动深度（四档）、实时自动回复、心跳待机与间隔。

## 注意

- 实时频道回复人格取决于当前主线聊天与角色卡；番外频道用角色档案 + 中枢联动资料。
- 中枢联动依赖「色色灵感状态栏/酒馆助手」的 AutoCardUpdaterAPI 与世界书数据——没装时自动跳过，不影响使用。
- 立绘保存在浏览器本地存储（localStorage），不会撑大酒馆设置文件；清浏览器数据会丢失立绘（档案与记录不受影响）。
- API 密钥仅保存在本地酒馆设置中。

## 安装

### 方式一：扩展面板一键安装（推荐）

扩展面板 → 安装扩展 → 粘贴 https://github.com/pkmao6/xuanshu-communicator

### 方式二：手动安装

将整个 xuanshu 文件夹放入 public/scripts/extensions/third-party/xuanshu/，刷新页面即可。

> 注意：不要同时保留「手动安装」和「面板安装」的两份拷贝，会开出两台终端哦。
