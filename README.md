# 玄枢通讯器

为 SillyTavern 制作的加密通讯终端插件 —— 只属于机主和淫宠们的秘密频道，剧情里嵌入，剧情外异步私聊。

> 仓库地址：https://github.com/pkmao6/xuanshu-communicator

## 功能

- **邀请制通讯录（故事角色档案）**：不依赖角色卡，为故事里的角色单独建档——名字 + 档案文本 + 外貌 Tag 档案（面部/发色/瞳色/体型/胸臀/服装/特征八类），随时可改、可踢。
- **立绘功能整体（照搬色色灵感状态栏交互）**：
  - 每位角色独立**图库面板**：标题计数、**批量删除/批量导出**、生成新立绘、导入本地图片；
  - 每张图可标注**情绪**与**场景（日常/瑟瑟）**，按标注**筛选**；
  - **随机立绘池**：≥2 张入池后每次刷新随机展示（终端头部/通讯录头像）；
  - 点图进**放大灯箱**：三槽滑动轨道、左右箭头/键盘/翻页、点图/空白/ESC 关闭；灯箱内可设为立绘/重新生图/编辑标签/删除；
  - **生成表单**：构图预设（默认/头像/半身像/全身像）× 主题（立绘/精彩瞬间/角色魅力/NSFW情节/情绪特写/服装展示）× 尺寸（默认/竖/横/方）× 本次额外提示词 × 人物 Tag 编辑器 × 生图内容可编辑区（开始生成后可直接改词重新生图）＋ 保存为偏好。
- **ComfyUI 生图**：粘贴主人自己的 API 格式工作流 JSON，仅替换 {{prompt}} {{negative}} {{seed}} {{width}} {{height}} 占位符。
- **分层提示词（正负词固定）**：质量词固定前缀 → 构图 → 表情（禁止加权） → 角色外貌（每个人物自己的 Tag 档案，服装可用自己档案或默认服装层） → 姿势 → 光影 → 主题 → 额外提示词 → 固定后缀；**按单个 tag 去重**，体型/身份特征保留括号权重。
- **独立 OpenAI 接口（全部频道通用）**：实时（带主线上下文）、番外、心跳都可直连 OpenAI 兼容接口；未配置自动回退酒馆主接口。
- **机主名字**：默认跟随当前人格名，可手动覆盖。
- **角色中枢联动（有依据的回复）**：世界书档案实时扫描 + TavernDB 表 + 纪要摘要（限流：世界书≤4000 字、角色表≤2000 字、纪要最近 5 条摘要≤800 字，总注入≤6000 字）。
- **心跳待机**：淫宠们定时随机主动来讯，成员级开关。
- **斜杠命令**：/comm 系列。

## 使用

1. 刷新酒馆页面，右侧发光的 ◎ 按钮打开终端。
2. 点 ⚙ → 通讯录：填「角色名 + 角色档案」，点「建立档案并加入频道」；再点成员行「档案」完善档案与外貌 Tag。
3. 成员行点「**立绘**」进入该角色的**图库**：点「生成新立绘」打开生成表单（选构图/主题/尺寸 → 自动组装提示词 → 开始生成）；点图放大，灯箱里可设为立绘/重新生图/编辑标签/删除。
4. 「模型」区配置独立 OpenAI 接口（可选）；「立绘」区粘贴 ComfyUI 工作流 + 调整分层模板。
5. 终端顶部下拉切换「通讯对象」；回车发送，Shift+回车换行。

### 斜杠命令

| 命令 | 作用 |
| --- | --- |
| /comm 消息 | 以机主身份发消息进主线（发给当前对象），并自动生成回复 |
| /comm side 消息 | 在番外频道给当前对象发消息并生成回复 |
| /comm target 名字 | 切换当前通讯对象 |
| /comm invite 名字 | 为故事角色建档并加入频道 |
| /comm kick 名字 | 将角色移出频道（档案/图库/记录一并删除） |
| /comm members | 查看频道成员名单 |
| /comm reply | 手动触发回复主线频道上一条讯息 |
| /comm open / /comm close | 打开 / 关闭终端窗口 |

### 设置项

- **设备**：设备名、机主名字（留空 = 跟随当前人格名）。
- **通讯录**：建档制角色管理（档案 / 外貌 Tag / 心跳 / 中枢 / 踢出）。
- **模型（OpenAI 兼容接口）**：全部频道通用。
- **立绘（ComfyUI）**：地址、工作流 JSON（占位符替换）、尺寸、种子。
- **立绘提示词模板**：质量词前缀 / 构图 / 表情 / 默认服装层 / 姿势 / 光影 / 固定后缀 + 固定负面提示词；主题 tag 内置在生成表单里。
- **行为**：中枢联动深度（四档）、实时自动回复、心跳待机与间隔。

## 注意

- 中枢联动依赖「色色灵感状态栏/酒馆助手」的 AutoCardUpdaterAPI 与世界书数据——没装时自动跳过。
- 图库与立绘保存在浏览器本地存储（localStorage）；清浏览器数据会丢失图库（档案与记录不受影响）。
- API 密钥仅保存在本地酒馆设置中。
- 生成立绘前请先启动 ComfyUI 并填好地址；工作流里需要出图节点（SaveImage/PreviewImage）。

## 安装

### 方式一：扩展面板一键安装（推荐）

扩展面板 → 安装扩展 → 粘贴 https://github.com/pkmao6/xuanshu-communicator

### 方式二：手动安装

将整个 xuanshu 文件夹放入 public/scripts/extensions/third-party/xuanshu/，刷新页面即可。

> 注意：不要同时保留「手动安装」和「面板安装」的两份拷贝，会开出两台终端哦。
