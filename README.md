# 玄枢通讯器

为 SillyTavern 制作的加密通讯终端插件 —— 叶玄与淫宠之间的秘密频道，剧情里嵌入，剧情外异步私聊。

> 仓库地址：https://github.com/pkmao6/xuanshu-communicator

## 功能

- **实时频道（剧情嵌入）**：在终端输入讯息，会以「玄枢」的身份、终端样式的消息块投递进主线聊天流，跟着剧情走；淫宠的回复由 AI 静默生成后同样投递进主线，不打断剧情节奏。
- **番外频道（异步私聊）**：与主线完全隔离的独立频道，用淫宠的角色卡构建独立上下文生成回复，历史独立保存，主线聊天不受任何污染。
- **心跳待机**：开启后淫宠会每隔一段时间（带随机抖动）主动发来一条私讯，撒娇、汇报、挑逗随机切换。
- **斜杠命令**：`/comm` 系列，在聊天输入框里也能操控通讯器。
- **终端质感**：绿磷光 CRT 屏幕、扫描线、可拖拽窗口、未读讯息呼吸灯。

## 使用

1. 启动 SillyTavern 后，屏幕右侧会出现一个发光的圆形按钮（◎），点击打开/关闭终端。
2. 顶栏可拖拽移动窗口；⚙ 打开设置；– 收起；× 关闭。
3. 输入讯息后回车发送，Shift+回车换行。
4. 顶部标签切换「实时频道」与「番外频道」。

### 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/comm 消息` | 以叶玄身份通过通讯器发消息进主线，并自动生成淫宠回复 |
| `/comm side 消息` | 在番外频道发消息并生成回复 |
| `/comm reply` | 手动触发淫宠回复主线频道上一条讯息 |
| `/comm open` / `/comm close` | 打开 / 关闭终端窗口 |

### 设置项

- **设备名**：默认「玄枢」，主线聊天里装置消息的名字与样式跟随此名。
- **叶玄名字 / 淫宠角色卡名**：两个通讯双方的名字；淫宠角色卡名用于查找角色卡构建番外人设。
- **番外补充人设**：额外追加给番外频道的设定文本（可选）。
- **实时频道自动回复**：关闭后只投递消息，不自动生成淫宠回复（可手动 `/comm reply`）。
- **心跳待机 / 心跳间隔**：番外频道定时主动来讯。

## 注意

- 实时频道的回复质量取决于当前主线聊天使用的角色卡是否为「淫宠」；若不是，AI 仍会以设定名字回复，但人格可能借用当前角色卡。
- 番外频道完全不依赖当前聊天与角色卡以外的内容，只使用淫宠角色卡的描述/性格/背景/对话示例。
- 所有记录保存在 SillyTavern 的扩展设置中，清空频道记录不会影响主线聊天。

## 安装

### 方式一：扩展面板一键安装（推荐）

1. SillyTavern 右上角点开「扩展」面板
2. 点击「安装扩展 / Install extension」
3. 粘贴仓库地址：`https://github.com/pkmao6/xuanshu-communicator`
4. 点击安装，刷新页面后即可使用

### 方式二：手动安装

将整个 `xuanshu` 文件夹放入：

```
public/scripts/extensions/third-party/xuanshu/
```

然后重启 SillyTavern（或刷新页面）即可，在「扩展」面板里可以看到「玄枢通讯器」。

> 注意：不要同时保留「手动安装」和「面板安装」的两份拷贝，会开出两台终端哦。
